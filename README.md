# `librus-apix-homeassistant` - Librus dla Home Assistant

Integracja [HACS](https://hacs.xyz/) dla Home Assistant. Odczytuje dane ucznia z Librus Synergia (oceny, wiadomości, ogłoszenia, terminarz) i udostępnia je jako encje oraz wyzwalacze automatyzacji.

> [!WARNING]
> Projekt w budowie. Integracja nie jest jeszcze gotowa do użycia.

> [!IMPORTANT]
> Projekt nieoficjalny. Nie jest powiązany z firmą Librus ani przez nią wspierany.

Karty do panelu: [librus-apix-homeassistant-ui](https://github.com/Tomasz-Mankowski/librus-apix-homeassistant-ui).

## English

Home Assistant integration (HACS) that reads student data from Librus Synergia: grades, messages, announcements and schedule. The data is available as entities and automation triggers.

- **Status:** work in progress, not ready for use.
- **Disclaimer:** unofficial project, not affiliated with or endorsed by Librus.
